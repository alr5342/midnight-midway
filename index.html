The Midnight Midway — credits

Developer: Alex Rosemann. Concept direction, design decisions, review and testing by Alex Rosemann; code and artwork preparation assisted by OpenAI Codex/ChatGPT.

Visuals: Midnight Midway reference generated with ChatGPT, as confirmed by the Developer. Layer extractions, hidden-surface repairs, corrected gondola and spectral attendant prepared with OpenAI image generation. Bell and blank music paper were painted with OpenAI image generation using the scene as a style reference; exact notation, ticket, stamp, sparks, masks and ambient SVG effects are project-original code artwork. Original horse pixels were extracted without regeneration. No external font or runtime code library is used.

Wind: remaxim, Short wind sound. Filtered and crossfaded into the ambient loop.

Bell: Julie Damsgaard / Spring Spring / Spring Enterprises, Pleasing Bell Sound Effect. Pitched and faded into three ring cues.

Carousel notes: original code-synthesized music-box tones; no external recording. Preparation source is included in the project.

Prize game and ending: cans, counter and empty-field repair painted with OpenAI image generation using the approved reference. Brass token and effects are original SVG code. Throw, tin and winning chime sounds are original deterministic synthesis; no external recording. Exact prompts and preparation sources are included.

Magic: JaggedStone, Magic Spell SFX. Trimmed, pitched and faded for arrival, stamp and departure.

All external sounds are CC0 1.0. Full source URLs, preserved originals and processing details are recorded in the project’s CREDITS.md.
